# 部署指南

## 一、Vercel 部署（推荐）

### 1. 准备工作
1. 注册 [Vercel](https://vercel.com) 账号
2. 安装 Vercel CLI（可选）：`npm i -g vercel`
3. 将代码推送到 GitHub/GitLab/Bitbucket

### 2. 部署步骤
1. 登录 Vercel 控制台
2. 点击 "New Project"
3. 选择您的代码仓库
4. 配置项目设置：
   - **Framework Preset**：Next.js
   - **Root Directory**：`./`（如果代码在根目录）
   - **Build Command**：`npm run build`
   - **Output Directory**：`.next`
5. 点击 "Deploy"

### 3. 自定义域名
1. 在项目设置中点击 "Domains"
2. 添加您的域名
3. 按照提示配置 DNS 记录：
   ```
   类型：CNAME
   名称：www（或子域名）
   值：cname.vercel-dns.com
   ```
4. 等待 DNS 生效（通常几分钟到几小时）

### 4. 环境变量
1. 在项目设置中点击 "Environment Variables"
2. 添加您的环境变量（参考 `.env.local.example`）

## 二、Netlify 部署

### 1. 准备工作
1. 注册 [Netlify](https://netlify.com) 账号
2. 将代码推送到 GitHub/GitLab/Bitbucket

### 2. 部署步骤
1. 登录 Netlify 控制台
2. 点击 "New site from Git"
3. 选择您的代码仓库
4. 配置构建设置：
   - **Build command**：`npm run build`
   - **Publish directory**：`.next`
5. 点击 "Deploy site"

### 3. 自定义域名
1. 在站点设置中点击 "Domain management"
2. 添加自定义域名
3. 配置 DNS 记录：
   ```
   类型：CNAME
   名称：www（或子域名）
   值：your-site-name.netlify.app
   ```

## 三、GitHub Pages 部署（静态导出）

### 1. 配置静态导出
修改 `next.config.js`：
```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  output: 'export',
  // 其他配置...
}

module.exports = nextConfig
```

### 2. 构建和部署
```bash
# 构建静态文件
npm run build

# 部署到 GitHub Pages
# 1. 创建 gh-pages 分支
# 2. 将 out 目录内容推送到 gh-pages 分支
# 3. 在 GitHub 仓库设置中启用 GitHub Pages
```

## 四、自托管部署

### 1. 服务器要求
- Node.js 18+
- npm 或 yarn
- 稳定的网络连接

### 2. 部署步骤
```bash
# 1. 克隆代码
git clone your-repo-url
cd personal-homepage

# 2. 安装依赖
npm install

# 3. 构建项目
npm run build

# 4. 启动生产服务器
npm start

# 5. 使用 PM2 管理进程（推荐）
npm install -g pm2
pm2 start npm --name "personal-homepage" -- start
pm2 save
pm2 startup
```

### 3. Nginx 配置示例
```nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

## 五、域名配置详解

### 1. 主域名配置
用于个人主页主站，建议选择简短易记的域名。

### 2. 子域名配置
- `tools.yourdomain.com` - 工具子站
- `books.yourdomain.com` - 书籍子站
- `api.yourdomain.com` - API服务

### 3. DNS 记录示例
```dns
; 主域名
yourdomain.com.    IN    A    76.76.21.21
www.yourdomain.com. IN CNAME yourdomain.com.

; 子域名
tools.yourdomain.com. IN CNAME cname.vercel-dns.com.
books.yourdomain.com. IN CNAME cname.vercel-dns.com.
api.yourdomain.com.   IN CNAME cname.vercel-dns.com.
```

## 六、HTTPS 配置

### 1. Vercel/Netlify
自动提供 HTTPS，无需额外配置。

### 2. 自托管
使用 Let's Encrypt 免费 SSL 证书：
```bash
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

# 自动续期
sudo crontab -e
# 添加：0 12 * * * /usr/bin/certbot renew --quiet
```

## 九、常见问题

### Q1: 部署后页面空白
A: 检查控制台错误，通常是路径问题或环境变量未配置。

### Q2: API 路由不工作
A: 确保部署平台支持服务器端函数（Vercel/Netlify 支持）。

### Q3: 自定义域名不生效
A: 检查 DNS 配置，等待 DNS 生效（可能需要几小时）。

### Q4: 如何更新网站
A: 推送代码到 Git 仓库，部署平台会自动重新部署。
